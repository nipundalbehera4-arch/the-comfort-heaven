HOW TO USE
----------
1. Download and extract the website ZIP file.
2. Find the file named index.html.
3. Open index.html in a browser to preview the website locally.
4. To publish it on GitHub Pages, upload the website files to your GitHub repository.
5. Make sure the main page is named exactly index.html and is in the repository's publishing root.
6. Open the repository's Settings > Pages and configure GitHub Pages if it is not already enabled.
7. Commit and push your changes. Wait for GitHub Pages to finish publishing, then open the Pages URL.

UPDATING THE WEBSITE
--------------------
- To replace the website, upload the updated index.html and overwrite the old version.
- If the ZIP contains additional assets or files, keep the folder structure unchanged and upload those files too.
- After uploading, commit the changes and allow a short time for the live website to refresh.
- If an older version appears, refresh the page or clear the browser cache.
